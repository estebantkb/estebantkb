### System.out
I'm an Information Systems Engineering student based in Ecuador. I like to strip things down to the bare metal—understanding how systems communicate under the hood, building solid backend architectures, and squeezing extreme performance out of hardware.

When I'm not tuning servers or writing logic, I'm grinding games, exploring deep internet aesthetics, or listening to heavy tracks. I don't claim to know it all, but I know how to break things apart and figure them out.

- ⚙️ **Core:** Backend Development (Java / Spring Boot) & APIs.
- 🖥️ **Environment:** Linux Power User (Fedora / TTY) & Hardware Tuning.
- 🧠 **Focus:** Information Systems, Database Architecture & Docker.
